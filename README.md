# Frontend for Timetracker
For the assignment
Deployed [here](https://time.williameliasson.com)
Also see [the backend]([url](https://github.com/plugga-tech/timetracker-backend-williameliasson))
## Features
* User registration and login
* Admin page to view users total logged time (last 30 days) (username: admin, password: admin)
* create categories per user
* create sessions per user
* only one session active per user at one time
* edit category names
* change category per session
* statistics over ones own time spent (last 30 days)

## Tech
* React
* Typescript
* React router
